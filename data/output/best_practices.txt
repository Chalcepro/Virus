## Interface Segregation Principle
# Bad - Fat interface
class Worker(ABC):
    @abstractmethod
    def work(self):
        pass

# Good - Segregated interfaces
class Workable(ABC):
    @abstractmethod
    def work(self):
        pass

class Robot(Workable):
    def work(self):
        print("Robot working")

def eat(self):
        print("Human eating")

### Optimization Techniques
1. Use generators instead of lists for large data
2. Cache expensive computations (memoization)
3. Use sets for membership tests (O(1) vs O(n))
4. Avoid string concatenation in loops (use join)
5. Use built-in functions (map, filter) for speed
6. Consider numba/numpy for numerical operations
7. Profile before optimizing
